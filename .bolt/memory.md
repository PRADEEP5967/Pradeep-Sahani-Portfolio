# Project memory

## Product intent & audience

- Personal portfolio website showcasing the owner's profile and technical projects
- Audience: potential employers, clients, recruiters
- Includes a technology-focused portfolio area with project cards

## Brand personality & voice

- Professional, developer-oriented tone
- Project captions are concise and readable
- Emphasis on full-stack and modern web development capabilities

## Visual design & UX direction

- Hero section uses the owner's personal photo as the main profile image
- Same photo also serves as the site favicon
- Technology/portfolio section includes a sourced technology image (Pexels)
- Project cards display technology stack details with matching styling
- Technologies featured: .NET, React, Node.js, Azure, responsive design
- Layout uses card-based portfolio patterns

## Decisions, constraints & rationale

- Owner's personal photo is the canonical profile image across hero and favicon
- Technology imagery sourced from Pexels (external stock provider)
- Portfolio categorized around full-stack development, responsive design, and modern web applications
- File editing approach: locate exact lines before modifying to avoid whitespace mismatch failures

## Open questions & assumptions

- Portfolio may need real project links, descriptions, or live demos beyond placeholder captions
- Whether additional pages (About, Contact, Blog) are planned beyond current hero and portfolio
- Whether Pexels images should be replaced with owned/custom assets long-term
- Accessibility and responsive behavior not yet verified or discussed
- Exact color palette, typography, and spacing tokens not yet established explicitly
